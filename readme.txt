Программа симуляции гравитационного движения небесных тел

Из-за множества ресурсов (изорбажений, музыки) невозможно полностью залить на GitHub. Полную версию со всеми ресурсами смотрите на https://drive.google.com/drive/folders/1vedZk3JRJI4SW1-n33FK1PmZYbVY-VZq?usp=drive_link (Jar-файл по пути out/artifacts/Kursovaya_0_jar/Kursovaya.0.jar). 

Чтобы создать новую планету, нажмите кнопку "Create Planet" на панели у левой стороны экрана.
Далее выберите место, куда вы хотите поместить новую планету. Кликните на экран в определенном месте, чтобы там создалась планета.
После этого появиться форма создания планеты. В поле "Name" могут быть введенны любые символы, кроме букв кириллицы, или оно может быть оставлено пустым.
Поля "Mass" и "Radius" принимают только цифры. Чтобы стереть последний введенный символ, нажмите клавишу backSpace.
Под полями можно на свой вкус выбрать изображение для планеты.
Нажмите на изображение планеты, чтобы раскрыть селектор планет. Из раскрывшегося списка выберите нужное изображение кликнув на него.
После этого нажмите на кнопку "Create", чтобы завершить создание планеты.
В случае, если вы не хотите создавать планету, нажмите "Cancel" для закрытия формы.
После создания планеты, будет предложено задать её начальную скорость. Появится линия, одним концом прикрепленная к планете, а другим к курсору.
Направление этой линии определяет направление скорости планеты. Длина этой линии – её величину.
При небоходимости в дальнейшем можно будет переопределить скорость планеты кликнув по ней средней кнопкой мыши.
Удалить планету можно кликнув на неё два раза правой кнопкой мыши.
Чтобы вручную изменить координаты планеты, можно перетащить её, наведя на неё курсор и зажав правую кнопку мыши.
Масштаб изображения можно изменять с помощью колесика мыши. Можно переместить область видимости, зажав среднюю кнопку мыши и передвигая её.
